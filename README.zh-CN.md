# IAPM 软件包管理器 3.0 Dev
IAPM 是一个开发中的软件包管理器 (还未完成!)

## 依赖 ##
如果你有一个基本可用的操作系统，那么，Python、Tar 是目前的依赖项。 <br>
随着未来的功能更新，预计还会加入的依赖项如下： <br>
* GnuPG (签名、验证软件包)

## 快速开始 ##
尽管还没完成，但你可以先<del>乱耍一下</del>尝试这些步骤： <br>

1. 克隆仓库:
```bash
git clone https://github.com/playthe218/IAPM
```
2. 进入程序目录:
```bash
cd IAPM/src
```

3. 运行:
```bash
./main.py --test
```

**重要**: 由于 IAPM 3.0 处于开发阶段，请使用 `--test` 以免可能不正确的功能破坏系统。 <br>
